# BCNTA Followers

Application de suivi des membres de La Belle Église Internationale (comités, pointage, rapports, registre de l'église, culte).

**Adresse :** https://visus-thub.github.io/BCNTA-FOLLOWERS-/

## Fichiers (tous à la racine du dépôt)
- `index.html` : l'application
- `manifest.webmanifest`, `sw.js` : rendent l'application installable et utilisable hors ligne
- `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png` : icônes

## Installer sur un téléphone
- **Android (Chrome)** : ouvrir l'adresse, puis le bouton « 📲 Installer l'application » sous « Se connecter », ou menu ⋮ puis « Installer l'application ».
- **iPhone (Safari)** : Partager puis « Sur l'écran d'accueil ».

## Mise à jour
Remplacer `index.html` dans le dépôt. L'application installée se met à jour à l'ouverture suivante, quand le téléphone a du réseau.

## Sécurité
Aucun code d'accès n'est dans ces fichiers : ils sont dans les Propriétés du script Google (Apps Script).
